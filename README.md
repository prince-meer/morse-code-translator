# Morse Code Translator

**Live tool: https://morsecodetranslator.space**

A free Morse code translator that runs entirely in your browser — no sign-up, no data collected. Translate text to Morse code and back, listen to it as audio, flash it as light, decode it from your microphone, and learn with the built-in practice trainer.

## Features
- Two-way translator: text to Morse and Morse to text, instant
- Audio playback with adjustable speed (WPM) and tone, plus WAV download
- Light / flash signal translator and tap keyer
- Microphone decoder and practice trainer with scoring
- Printable Morse code chart, alphabet, numbers and phrase pages

## Who it is for
Ham radio learners, students, teachers, Scout groups (JOTA-JOTI), and anyone who needs to send or read a quick Morse message — including SOS.
